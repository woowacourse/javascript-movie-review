# javascript-movie-review

FE 레벨1 영화 리뷰 미션

## 공통 요구사항

- [ ] 영화 포스터나 제목을 클릭하면 자세한 예고편이나 줄거리 등의 정보를 보여준다.
- [ ] 별점을 남길 수 있는 기능을 만든다.
- [ ] 반응형 웹을 구상하여 디바이스의 너비에 따라 유동적으로 레이아웃이 조절되는 멋진 UI를 구현한다.

## 기능 목록

### 1. 영화 상세정보 조회 모달

- [ ] 영화 제목이나 포스터 클릭 시 모달을 표시한다.
- [ ] 모달에서 보여줄 상세 정보
  - 영화 포스터
  - 영화 제목
  - 영화 장르
  - 평균 별점
  - 줄거리
- [ ] 모달 닫기
  - ESC 키를 누르는 경우
  - 모달 외부 배경을 클릭하는 경우
  - 닫기 버튼을 클릭하는 경우

### 2. 별점 매기기

- [ ] 2점 단위로 구성 (2 / 4 / 6 / 8 / 10점)
  - 2점 : 최악이예요
  - 4점 : 별로예요
  - 6점 : 보통이예요
  - 8점 : 재미있어요
  - 10점 : 명작이예요
- [ ] 별점 선택 시 localStorage에 저장한다.
- [ ] 새로고침 후에도 사용자가 남긴 별점을 유지한다.

### 3. 영화 목록 무한 스크롤

- [ ] IntersectionObserver를 사용하여 무한 스크롤을 구현한다.
- [ ] 브라우저 화면 끝에 도달하면 다음 20개 영화를 요청한다.

### 4. 반응형 웹

- [ ] 웹 / 모바일 환경에 따른 반응형 레이아웃을 구성한다.

### 5. E2E 테스트 작성

- [ ] 영화 포스터 또는 제목 클릭 시 모달 창 표시
- [ ] 닫기 버튼 클릭 시 모달 닫기
- [ ] ESC 키로 모달 닫기
- [ ] 별점 부여 후 새로고침 시 별점 유지
- [ ] 무한 스크롤 동작
