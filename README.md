# javascript-movie-review

FE 레벨1 영화 리뷰 미션

## 요구사항 명세서

### 영화

- [x] 영화 리스트를 불러온다.
- [x] 영화 섹션 하나에 포스터, 평점, 영화 제목을 띄운다.
- [x] 영화 목록을 띄울 때 20개씩 띄운다.
- [ ] 검색어에 따른 필러링된 영화 리스트를 불러온다.

### 세부 정보 모달

- [ ] 영화 포스터를 누르면 세부 정보 모달을 띄워서 영화의 개요를 띄운다.
- [ ] 세부 정보 모달은 포스터, 평점, 영화 제목, 설명을 포함한다.
- [ ] 세부 정보 모달은 x버튼, 백그라운드 클릭, esc 버튼으로 닫을 수 있다.

### 더 보기 기능

- [x] '더보기' 버튼을 누르면 영화 20개를 추가로 띄운다. (띄운 후 아래 '더보기' 버튼 또 생김)

### 검색 기능

- [x] 검색란에 영화 제목을 입력해서 검색 버튼, Enter키를 눌러 필터링된 영화 20개를 띄운다.
- [ ] 검색 결과가 존재하지 않으면 "검색 결과가 없습니다" 텍스트를 띄운다.
- [x] 검색 결과 화면에서 검색란에 검색어가 존재하지 않은 상태에서 검색버튼을 누르면 원상복귀.

## 테스트 시나리오

- [ ] '더보기' 버튼을 눌러 페이지를 확장시키면 영화 개수가 20개씩 늘어난다.
- [ ] 검색란에 검색어를 입력하고 검색 버튼, Enter키를 누르면 필터링된 영화 목록을 보여준다.
- [ ] 검색란에 검색어를 입력해도 결과가 존재하지 않다면 "검색 결과가 없습니다" 텍스트를 띄운다.
- [ ] 영화 포스터를 누르면 세부 정보 모달이 나타난다.
- [ ] 모달의 'x' 버튼, 백그라운드 영역, esc 버튼을 클릭하면 모달이 닫힌다.
