# javascript-movie-review

FE 레벨1 영화 리뷰 미션

## 🛠 주요 기능

1. 영화 목록 조회

- [x] 초기 렌더링: 페이지 접속 시 영화 20개를 화면에 출력합니다.
  - [x] 인기 영화 GET API 요청 테스트 (page 1 GET API)

- [x] 더 보기(Pagination): '더 보기' 버튼 클릭 시 20개의 영화를 추가로 불러옵니다.

- [x] 예외 처리: 더 이상 불러올 영화 데이터가 없는 경우 '더 보기' 버튼을 제거합니다.

2. 영화 검색 기능

- [x] 검색 실행: 입력창에 키워드를 입력하고 엔터(Enter) 키를 누르거나 검색 버튼을 클릭하여 검색을 수행합니다.

- [x] 동적 데이터 로드: 검색어 기반으로 영화 데이터를 페칭합니다.

- [x] 검색 결과 페이징: 검색 결과가 20개를 초과할 경우, '더 보기' 버튼을 통해 추가 결과를 로드합니다.

- [x] 스켈레톤 이미지 처리

- [x] 배너 DOM 제거 및 추가

- [x] 결과 없음 처리: 검색 결과가 존재하지 않을 경우 "검색 결과가 없습니다"라는 안내 메시지를 출력합니다.

## step2

1. 영화 상세 정보 조회

- [x] 영화 포스터 클릭 시 모달 창을 통해 상세 정보를 표시합니다.
- [x] API에서 제공하는 항목(제목, 포스터, 평점, 개봉연도, 장르, 줄거리)을 활용하여 상세 정보를 보여줍니다.
- [x] ESC 키를 누르거나 모달 외부 영역 또는 닫기 버튼 클릭 시 모달을 닫을 수 있습니다.

2. 별점 매기기

- [x] 사용자는 영화에 대해 별점을 줄 수 있습니다.
- [x] 새로고침 후에도 사용자가 남긴 별점은 유지됩니다. (localStorage 사용)
- [x] 별점은 5개로 구성되며 한 개당 2점입니다. (1점 단위 미지원)
  - 2점: 최악이예요 / 4점: 별로예요 / 6점: 보통이에요 / 8점: 재미있어요 / 10점: 명작이에요

3. 무한 스크롤 만들기

- [x] 더보기 버튼 삭제
- [x] 사용자가 스크롤 끝에 도달하면 다시 로딩

3. UI/UX 개선
