FE 레벨1 영화 리뷰 미션 (step-2)

## 기능 목록

### Step 2

#### 1. 영화 상세 정보 모달

(기본)

- 영화 카드 클릭 시 상세 정보 모달을 표시한다.(포스터, 제목, 장르, 평점, 줄거리)
- 윤돌: 클릭이벤트를 고민해보자 -> 이벤트 위임? 타겟?

(UX)

- 모달이 열리면 닫기 버튼으로 포커스가 이동한다.
- 모달 외부 클릭을 해도 닫히지 않는다. (고민중... 애매...)
- 모달이 열린 동안 배경 스크롤을 막는다.
- (윤돌의견: 줄거리 부분은 내부 스크롤을 하는게 좋아보인다.)
- 닫기 버튼 클릭 시 모달을 닫는다.
- ESC 키를 눌러 모달을 닫는다.

#### 2. 별점 매기기

(기본)

- 사용자는 모달에서 영화에 별점(2~10점)을 줄 수 있다.
- 별점은 한 개당 2점이다.
- 별점에 따라 텍스트를 표시한다: 2, 4, 6, 8, 10점
- 새로고침 후에도 사용자가 남긴 별점이 유지된다.
- 별점 저장소는 localStorage와 서버 API를 교체할 수 있는 구조로 구현한다.
- 가장 가까운 별을 클릭했을때, 그 별을 찾아서 왼쪽부터 전부 채운다.

- (윤돌의 생각) 1. 사용자가 클릭한 별의 id를 뷰에게 전달한다. 2. 뷰는 받은 id값으로 채워진 별을 반복문을 통해 생성한다. 빈 별 갯수 - 클릭했을때 받은 별을 추가한다.

(UX)

- 별에 hover 하면 해당 점수까지 미리 채워진 느낌을 준다.

#### 3. 무한스크롤

(기본)

- 더보기 버튼을 제거한다.
- `IntersectionObserver` 기반의 무한스크롤로 변경한다.
- 목록 맨 아래 sentinel 요소가 뷰포트에 진입하면, 다음 페이지를 자동으로 요청한다.
- 다음 페이지 로딩 중 스켈레톤을 표시한다.
- 마지막 페이지에 도달하면 observer를 해제하여 추가 요청을 하지 않는다.

#### 4. 반응형 레이아웃

(기본)

- 데스크탑, 태블릿, 모바일 너비에 따라 레이아웃이 바뀐다.
- 영화 목록 한 행의 카드 수가 디바이스 너비에 따라 바뀐다.
- 모달도 디바이스 너비에 맞게 조절된다.
