# javascript-movie-review

FE 레벨1 영화 리뷰 미션

- 영화 목록 조회
  - [ ] 인기있는 영화 목록을 조회한다.
    - [ ] 더보기 버튼을 누르면 다음 영화 목록을 불러온다.
      - [ ] 더 이상 요청할 페이지가 없는 경우 `더보기` 버튼을 노출하지 않는다.
    - [ ] 한 번의 요청당 20개씩 영화 목록을 불러온다.
  - [ ] 영화 목록을 불러오는 동안 Skeleton UI를 보여준다.
- 검색
  - [ ] 내가 보고 싶은 영화를 검색한다.
    - [ ] 검색한 결과가 없을 때 ‘검색 결과가 없습니다.’를 화면에 출력한다.
- 예외 처리
  - [ ] 이미지 src → 엑박 , 존재하지 않는 이미지 → fallback 이미지로..
  - [ ] 조회/ 검색 시 데이터를 불러오지 못했을 때
- e2e 테스트
  - [ ] maxPage일 때(e.g. 500) 엣지 케이스
